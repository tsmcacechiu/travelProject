## 一、專案概覽

以 [mntn.krystonschwarze.com](https://mntn.krystonschwarze.com/) 為視覺設計參考，打造一個兼具深度內容與實用工具的旅遊知識平台。整體架構拆分為三個子系統，各自有獨立定位與技術邊界。

---

## 二、技術架構

### 前端
- **框架：** React + Next.js 15 (App Router)
- **語言：** TypeScript
- **樣式：** Tailwind CSS
- **資料夾：** `travel-frontend/`

### 後端
- **框架：** Spring Boot 3
- **語言：** Java 25
- **API 規範：** RESTful JSON API
- **資料夾：** `travel-backend/`

### Folder 結構（Monorepo 風格）

```
TravelProject/
├── travel-frontend/         # Next.js + TypeScript 前端
│   ├── app/
│   │   ├── (site)/          # 核心品牌網站 (A)
│   │   ├── countdown/       # 生命倒數計時表 (B)
│   │   └── shop/            # 代購系統入口 (C)
│   ├── components/
│   ├── lib/
│   └── public/
│
├── travel-backend/          # Spring Boot 3 + Java 25 後端
│   ├── src/main/java/
│   │   └── com/travel/
│   │       ├── article/     # 旅遊文章模組 (A)
│   │       ├── guide/       # 旅遊攻略模組 (A)
│   │       ├── countdown/   # 倒數計時模組 (B)
│   │       └── shop/        # 代購模組 (C)
│   └── src/main/resources/
│
└── spec/                    # 規格文件
```

## 四、子系統規格

---

### A. 核心品牌網站（整合類）

**定位：** 旅遊知識庫  
**入口路徑：** `/`（首頁）、`/articles`、`/guides`

#### A1. 個人旅遊文章系統

| 欄位 | 說明 |
|------|------|
| 文章列表 | 卡片式展示，含封面圖、標題、日期、標籤 |
| 文章詳情 | Markdown 渲染、TOC 目錄、閱讀進度條 |
| 分類 / 標籤 | 依國家、主題分類 |
| 搜尋 | 全文搜尋（後端支援） |
| SEO | Next.js Metadata API、OG 圖片 |

**後端 API：**
```
GET  /api/articles          # 文章列表（分頁、篩選）
GET  /api/articles/{id}     # 文章詳情
GET  /api/articles/tags     # 標籤列表
POST /api/articles          # 新增（需驗證）
PUT  /api/articles/{id}     # 更新（需驗證）
DELETE /api/articles/{id}   # 刪除（需驗證）
```

#### A2. 旅遊攻略系統

| 欄位 | 說明 |
|------|------|
| 攻略列表 | 依目的地或主題分類 |
| 攻略詳情 | 支援嵌入地圖、PDF 下載連結 |
| 實用資訊 | 費用試算、交通建議、注意事項 |

**後端 API：**
```
GET  /api/guides            # 攻略列表
GET  /api/guides/{id}       # 攻略詳情
POST /api/guides            # 新增（需驗證）
```

---

### B. 工具型頁面 — 生命倒數計時表（優先開發）

**定位：** 極簡哲學工具、網站彩蛋  
**入口路徑：** `/countdown`  
**風格：** 獨立 Landing Page，黑白極簡，與旅遊主站風格刻意區隔

#### B1. 核心功能

| 功能 | 說明 |
|------|------|
| 生日輸入 | 使用者輸入出生年月日 |
| 預期壽命設定 | 預設 80 歲，可自訂（70～100 歲） |
| 剩餘時間顯示 | 年 / 月 / 週 / 天 / 小時 / 分 / 秒（即時更新） |
| 人生進度條 | 視覺化顯示已用時間百分比 |
| 已過去的週數 | 以小格子視覺化展示（靈感來自 Wait But Why） |
| 哲學語錄 | 每次載入隨機顯示一句關於時間的語錄 |
| 資料持久化 | LocalStorage 儲存（無需登入） |

#### B2. 頁面設計（UI Flow）

```
[全螢幕黑色背景]
  ↓
[輸入生日 + 預期壽命] → 按下「開始計算」
  ↓
[動畫展開：剩餘時間大字體倒數]
[進度條：你已走過 XX% 的人生]
[週格子視覺化]
[底部：哲學語錄]
```

#### B3. 技術細節

- **前端：** 純 Client Component（`use client`），無需 SSR
- **計算邏輯：** `date-fns` 或原生 JS Date
- **動畫：** Framer Motion
- **後端：** 此功能不需要後端 API（純前端運算 + LocalStorage）

#### B4. 後續擴展（選用）

- 分享功能：產生帶參數的分享連結 `/countdown?birth=19900101&life=80`
- 訂閱提醒：每年生日前 Email 提醒（需後端）

## 七、環境設定（初步）

### 前端環境變數（`.env.local`）
```env
NEXT_PUBLIC_API_URL=http://localhost:8080
```

### 後端設定（`application.yml`）
```yaml
server:
  port: 8080
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/traveldb
    username: ${DB_USER}
    password: ${DB_PASS}
  jpa:
    hibernate:
      ddl-auto: update
```
