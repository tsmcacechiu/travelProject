# 泰國 dm.html 行程總覽改版設計

日期：2026-08-12
範圍：`TravelDetail/Tailand-202610/dm.html`（不含 spa.html，本次不動）

## 背景 / 問題

目前 `dm.html` 的「行程總覽」（`.day-nav`，各日期快速跳轉列）只是一個放在 `main` 內的一般區塊，不是吸頂元素，使用者往下捲動後就看不到，無法隨時跳轉。此外整體排版偏舊式（單欄卡片 + 分隔線），使用者希望改成與 `Seoul-202609/seoul.html` 相近的雜誌感編輯排版，並增加插圖與照片版位。

## 設計目標

1. 「行程總覽」（日期快速跳轉）永遠可見，捲動不會消失。
2. 版面風格向 `seoul.html` 看齊：大字級日期編號、雜誌感留白、逐日插圖 banner、捲動淡入動畫。
3. 保留泰國頁現有色系（深蓆藍 `--deep-teal` / 金褐 `--gold` / 紅土 `--terracotta` / 米杏 `--cream`），不改用 Seoul 的墨藍/紅配色，避免與尚未改版的 `spa.html` 產生風格斷裂。
4. 每天可放多張照片，且照片是「錦上添花」——沒有照片檔案時，頁面仍完整好看（插圖 fallback），不會出現破圖或空白區塊。

## 設計內容

### 1. 導覽：單一吸頂列
把現有 `.phase-nav`（階段一/二/三 + SPA 連結）與 `.day-nav`（10/23–10/31 日期跳轉）合併成同一個 `position: sticky; top:0` 容器，內部分兩排：
- 上排：階段連結（階段一／二／三／SPA），沿用現有樣式。
- 下排：日期 chip 列（10/23（五）…10/31（六）），沿用現有 pill 樣式。

手機版（`max-width:640px`）下排日期 chip 改為橫向捲動（`overflow-x:auto; white-space:nowrap`），避免吸頂列過高吃掉版面。

### 2. 封面（hero）
改造成 Seoul `cover` 的編輯感版型，但延用泰國配色：
- 深蓆藍漸層底 + 現有 lotus/山巒剪影 SVG 加大鋪滿。
- 金色 eyebrow 小標籤（如 `BANGKOK × CHIANG MAI · NATURE & WELLNESS`，現有內容）。
- 大字級襯線主標題（沿用現有 h1 文案）。
- 新增一列統計資訊（仿 Seoul `cover-meta`）：出發日期／回程日期／天數／亮點數量，取代現有純文字段落式介紹（介紹文字保留，移到統計列下方）。

### 3. 逐日插圖 banner ＋ 照片小相簿（每日皆有，插圖恆顯示，照片可有可無）
每個 `.day-card` 頂部新增：

- **插圖 banner**（恆顯示，設定當日氛圍）：仿 Seoul `.shot` 結構，各日主題對應現有 SVG symbol／新增剪影：
  - 10/23 抵達曼谷 → 飛機／夜航
  - 10/24 曼谷→清邁 → 廟宇飛簷剪影
  - 10/25 廚藝課＋按摩＋夜市 → 廚房／市集剪影
  - 10/26 Mae Kampong → 森林＋瀑布剪影
  - 10/27 瑜珈＋僧侶步道＋騎馬 → 山寺＋馬剪影
  - 10/28 大象保護區＋竹筏 → 大象＋溪流剪影
  - 10/29 手作＋寧曼路 → 藍染／寧曼街景剪影
  - 10/30–10/31 曼谷 → 曼谷天際線剪影

- **照片小相簿**（有照片才顯示，2～4 格）：插圖 banner 下方新增 `.photo-grid`，內含數個 `.photo-item > img`，檔名慣例 `img/{day-id}-1.jpg`、`-2.jpg`…（例如 `img/d1025-1.jpg`）。每張圖 `onerror` 移除自身所在的 `.photo-item`；`.photo-grid` 使用 `:not(:has(.photo-item))` 在全部照片缺席時自動隱藏整列（純 CSS，不需 JS）。使用者之後只要把照片依檔名放進 `img/` 資料夾即自動出現，不需改 HTML。

### 4. 行程內容列式（取代現有 `.slot`）
比照 Seoul `.item`：左側時段/標籤（如「上午」「下午｜美學與按摩」），右側標題＋內文；標題旁可掛：
- 小色塊 chip（例如「預約制」「彈性」「用餐」），對應現有文字語意萃取。
- 「地圖」pill 連結，統一收斂現有零散的 Google Maps 超連結樣式。
日期編號改成大字級襯線數字（01–09），取代現有小型日期 pill，放在每個 `day-card` 標題區。

### 5. 亮點區塊 / footer
現有 `.highlights`（深蓆藍底、金字標題）已與 Seoul `.notes` 精神一致，僅微調字級與間距，不用重做結構。Footer 維持現有簡單文字列。

### 6. 動畫與 RWD
比照 Seoul 加入 `.rv` / `.rv.in` 捲動淡入效果（`IntersectionObserver`，`prefers-reduced-motion` 時關閉動畫）。RWD 斷點與行為對齊 Seoul（單欄化、`.item` 改為上下堆疊、吸頂列日期 chip 橫向捲動）。

## 不在範圍內

- `spa.html` 本次不動（後續如需求再另外處理）。
- 不會去外部下載/生成真實照片；只建立照片版位與檔名慣例，供使用者日後自行放入。
